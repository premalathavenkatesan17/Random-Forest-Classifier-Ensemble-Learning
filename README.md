# 🌲 Implementation of Random Forest Classifier for Ensemble Learning

## 📌 Project Overview

This project demonstrates the implementation of the **Random Forest Classifier**, a popular ensemble learning algorithm, using the **Breast Cancer Wisconsin Dataset**.

The Random Forest algorithm combines multiple decision trees to improve prediction accuracy and reduce overfitting.

---

## 🎯 Objective

The main objective of this project is to implement a Random Forest Classifier for classification and evaluate its performance using standard machine learning evaluation metrics.

---

## 📊 Dataset

**Dataset Name:** Breast Cancer Wisconsin Dataset

The dataset contains medical measurements that are used to classify breast cancer cases.

### Dataset Information

* Number of Samples: 569
* Number of Features: 30
* Target Column: `target`
* Machine Learning Task: Classification

## 🤖 Algorithm Used
